# PaperWeave

PaperWeave — проект исследовательского рабочего пространства для подготовки научных статей на основе библиотеки публикаций, проверяемых доказательств и редактируемого автором текста.

Проект пока находится на этапе документации и проектных предложений. Кода приложения, runtime-конфигурации и работающих функций ещё нет. Название продукта и технические решения остаются предложениями, пока владелец проекта не примет соответствующие ADR.
