# PaperWeave

PaperWeave — проект исследовательского рабочего пространства для подготовки научных статей на основе библиотеки публикаций, проверяемых доказательств и редактируемого автором текста.

Проект находится на этапе первичного каркаса: структура каталогов создана, а файлы приложения содержат только заглушки. Рабочих функций и проверенной runtime-конфигурации пока нет. Предлагаемый стек и архитектурные решения остаются проектными предложениями, пока владелец проекта не примет соответствующие ADR.
