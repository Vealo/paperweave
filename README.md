# PaperWeave

PaperWeave — проект исследовательского рабочего пространства для подготовки научных статей на основе библиотеки публикаций, проверяемых доказательств и редактируемого автором текста.

Принятая граница MVP — локальная основа с Vue + PrimeVue 4 + TypeScript, FastAPI и PostgreSQL: health-проверки, создание/просмотр исследовательских проектов и сохранение данных между перезапусками. Граница закреплена в принятом [ADR-0006](docs/decisions/ADR-0006-mvp-boundary.md); реализация выполняется по фазам из [IMP.md](IMP.md), текущий статус — в [TODO.md](TODO.md).

Для первого запуска выполните `make init`, при необходимости измените `config.toml`, затем `make config-check` и `make up`. Настройка приложения читается из TOML; `.env` не является её источником. Текущая узкая версия хранит исследовательские проекты в PostgreSQL и предоставляет health API, список, создание и просмотр проектов в Vue UI. Дальнейшие предметные области добавляются отдельными ADR и фазами IMP.
