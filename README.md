# PaperWeave

PaperWeave — проект исследовательского рабочего пространства для подготовки научных статей на основе библиотеки публикаций, проверяемых доказательств и редактируемого автором текста.

Принятая граница MVP — локальная основа с Vue + PrimeVue 4 + TypeScript, FastAPI и PostgreSQL: health-проверки, локальные owner-managed accounts, серверные сессии, проекты с проверкой владения и сохранение данных между перезапусками. Граница закреплена в [ADR-0006](docs/decisions/ADR-0006-mvp-boundary.md) и [ADR-0007](docs/decisions/ADR-0007-local-identity-and-project-access.md); реализация выполняется по фазам из [IMP.md](IMP.md), текущий статус — в [TODO.md](TODO.md).

Для первого запуска выполните `make init`, при необходимости измените `config.toml`, затем `make config-check` и `make up`. При первом открытии UI создайте owner account; последующие пользователи создаются владельцем через раздел «Пользователи». Настройка приложения читается из TOML; `.env` не является её источником. Подробности — в [локальном runbook](docs/runbook-local.md). Дальнейшие предметные области добавляются отдельными ADR и фазами IMP.
