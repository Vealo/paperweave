# ADR-0008: Цитирование и редактируемый DOCX

- Статус: Принято
- Дата: 2026-10-19
- Владелец решения: Denis Karmalak
- Связанные документы: [SPEC-2026-004](../specs/spec-2026-004-citations-export.md), [TASK-013](../../tasks/TASK-013.md)

## Контекст

Для P8 нужен узкий экспортируемый результат поверх ручной библиотеки проекта.
Текущая модель хранит автора, заглавие, год и DOI, а рукопись — версионируемый
Tiptap JSON. Цитирование должно ссылаться на библиотечную запись и сохранять
исходную рукопись неизменной.

## Решение

- MVP экспортирует редактируемый DOCX.
- Внутритекстовые библиографические ссылки — числовые ссылки в квадратных скобках
  по ГОСТ Р 7.0.5–2008. Описания списка литературы ориентируются на
  ГОСТ Р 7.0.100–2018.
- Citation node хранит ID записи источника, а не копию метаданных или доказательства.
- Номер определяется первым появлением источника в тексте; повторные ссылки
  используют тот же номер.
- Используются только введённые вручную поля текущей записи. Отсутствующие поля
  обозначаются явно; автоматическое обогащение запрещено в этой фазе.
- Экспорт доступен владельцу проекта, читает только сохранённую версию и не
  меняет документ или историю версий.
- Невалидная/чужая ссылка считается ошибкой экспорта, не удаляется молча.

Полное соответствие правилам библиографического описания не заявляется до
расширения модели метаданными и уточнения конкретных типов источников.

## Последствия

Автор получает переносимый редактируемый файл с согласованными номерами цитат.
Ограниченные поля означают, что библиографические записи остаются неполными для
некоторых видов публикаций; интерфейс/экспорт должны показать это, а будущий
доменно-ограниченный ADR может добавить форматы источников и новые поля.

## Рассмотренные варианты

- **DOCX** выбран как редактируемый формат русскоязычного MVP.
- PDF не выбран, поскольку не является целевым редактируемым исходником статьи.
- Внешнее обогащение библиографии не выбрано: оно передавало бы данные наружу и
  превышало текущую границу локального ручного ввода.
